# 项目目标与需求映射

来源：`C:/Users/14106/Downloads/【项目目标】.docx`，于 2026-10-12 提取正文。原文快照见 [source-document.txt](source-document.txt)，仅作来源核对。

## 产品目标

建设高性能秒杀购物商城，突出高性能、低延迟、防超卖、防刷、削峰填谷与最终一致性，可用于求职展示与压测演示。商城须具备商品浏览、用户与商品管理、下单、支付状态管理和后台管理接口，不应仅实现一个扣库存演示接口。

| G06 | MySQL | 商品、库存、订单、用户、支付记录、对账数据持久化；条件更新或乐观锁防超卖 |
| G07 | Nginx | 反向代理、静态资源缓存、基础限流、负载均衡 |
| G08 | Docker | 服务独立容器，一键启动，压测环境可复现 |
| G09 | 防刷 | IP 与用户限流、黑名单、验证码、动态秒杀地址、一人一单；前端阻止无效重复点击 |

| G13 | 状态区分 | 预扣成功、下单成功、支付成功必须独立可查 |

## 工程推导与可调整默认值

以下用于补齐可运行设计，不冒充原文已经规定的选择：

- 若没有既有前端，默认 Vue 3 + TypeScript；React 同样符合原文。
- 默认 Linux 容器作为 C++ 运行环境；本机 Windows 用于开发和编排，不假设已装 WSL/Docker。
- 默认开发阶段模拟支付，标明模拟边界；真实支付需补充渠道和回调契约。
- 默认一次抢购一件，购买资格维度为活动 + 商品/SKU + 用户；取消后默认不再次放开资格，若用户要求允许重抢则同步调整状态机和唯一约束。
- 项目根目录为 `E:/c++project/seckill-mall`，代码按 `src/seckill/`、`src/mq/`、`src/order/`、`src/web/` 拆分；父工作区的 `mq_project/`、网络库、缓存与日志项目只是待评估候选，不代表已经可接入或满足高可用。

## 已采纳的实施默认值

采用Vue3、Java21/Boot3.5.16、C++20、Redis7.2.11、MySQL8.4；MQ已按用户要求改RocketMQ，S0独立MQ决策被替代；库存事务划拨、数量1、关闭不释放资格、15分钟过期、开发MOCK支付。受理刷盘与可靠转发见[决策记录](../../../../docs/DECISIONS.md)和[架构](../../../../docs/ARCHITECTURE.md)。实现默认值变更同步ADR。

S4采用DB库存父锁/请求幂等事务与持久outbox；30分钟未产生订单的在途请求尝试写DB终止记录后回补，迟到消息不复活。该期限是可调整的实施默认值，不代表原文要求或生产恢复SLA；具体参数和恢复边界见[订单运行说明](../../../../docs/ORDER-RUNTIME.md)。
