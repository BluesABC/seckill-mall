## 项目定位

一个运动鞋秒杀商城，包含普通商品浏览和限时秒杀。风格要年轻、运动、干净、有抢购氛围，但不要廉价杂乱。

## 默认技术栈

Vue3 + Vite + TypeScript + Tailwind CSS。

如果用户指定 React、Next.js、原生 HTML/CSS/JS 或其他技术栈，则以用户指定为准。

## 需要设计的页面

1. 首页：顶部公告、导航栏、搜索、用户/购物车入口、Hero 大图、分类入口、热门秒杀、新品推荐、热卖商品、品牌故事、页脚。
2. 商品列表页：筛选、排序、商品网格、分页/加载更多。
3. 商品详情页：图片画廊、鞋款信息、尺码选择、价格、促销标签、加入购物车、秒杀倒计时、库存进度、推荐商品。
4. 购物车/结算页：商品清单、数量修改、优惠信息、合计、结算按钮。
5. 秒杀专区：倒计时、场次切换、库存进度条、抢购按钮、已抢百分比。
6. 登录/注册页可选，风格保持一致。

## 设计系统模板

### 色彩

- 主色：默认 `#111111`
- 背景色：默认 `#FFFFFF`
- 表面色：默认 `#F5F5F5`
- 强调色：默认高饱和运动色，例如 `#FF3B30`，可根据参考图替换
- 成功色：`#16A34A`
- 警告色：`#F59E0B`
- 危险色：`#DC2626`
- 主文字：`#111827`
- 次文字：`#6B7280`
- 弱文字：`#9CA3AF`
- 边框/分割线：`#E5E7EB`

如果参考图中有明确配色，必须覆盖以上默认值。

### 字体

- Hero 标题：`clamp(32px, 6vw, 72px)`，字重 800，行高 1.05
- 区块标题：32-48px，字重 700，行高 1.1
- 正文：14-16px，字重 400，行高 1.6
- 价格：20-28px，字重 800，行高 1.2
- 按钮：14-16px，字重 600
- 标签：12-14px，字重 600

### 间距

使用 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 的节奏。

### 圆角

- 卡片：12-16px
- 按钮：8-12px 或全圆角
- 标签：全圆角
- 图片容器：12-16px

### 阴影

- 卡片默认：`0 1px 2px rgba(0,0,0,.06), 0 8px 24px rgba(0,0,0,.08)`
- 卡片 hover：加深阴影并轻微抬升
- 秒杀按钮：可用强调色光晕，但不要过度

### 按钮

- 主按钮：黑底白字，hover 反转或变强调色
- 次按钮：白底黑边，hover 黑底白字
- 文字按钮：无背景，hover 下划线或变色
- 秒杀按钮：高饱和强调色，带倒计时或紧迫感文案
- 禁用状态：40% 透明度，禁止点击

### 商品卡片

- 图片比例：1:1 或 4:5
- 标题：最多 2 行截断
- 副标题：灰色，1 行截断
- 价格：粗体
- 划线价：灰色删除线
- 折扣标签：强调色或黑色
- 库存标签：剩余少量时用警告色

### 栅格与断点

- 移动端优先
- sm：640
- md：768
- lg：1024
- xl：1280
- 2xl：1440
- 商品网格：移动 2 列，平板 3 列，桌面 4 列
