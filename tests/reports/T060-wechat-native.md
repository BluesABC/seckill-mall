# T060 微信 Native 接入代码与本地验证

日期：2026-11-02，Asia/Shanghai。关联G01/G03/G06/G08。用户已明确尚无商户号，先完成代码与本地验证。阶段结论：接入代码本地验收完成；真实微信商户联调未完成，未启用真实收款。

## 实现

- 官方wechatpay-java0.2.17、公钥模式、Native预下单、服务端本地ZXing二维码、微信主动查单与关闭、全额退款/退款查询、支付及退款通知验签解密，普通与秒杀订单均接入。
- wx_payments持久意图/唯一商户单号，微信关闭确认前禁止本地释放库存；网络结果未知保留状态。回调和查单共用核对金额/CNY/商户/AppID/交易号的落账事务，重复通知不重复记账，原秒杀继续走outbox。
- 退款PROCESSING不算成功，确认后普通未发货库存只恢复一次，秒杀只做资金退款不恢复资格。已关单迟到成功不复活库存，登记原路退款补偿；异常退款REVIEW禁止发货，管理员可重新查渠道，不提供强制置成功接口。
- 预下单与查询租约分开（009迁移），修复查单任务可能占住二维码恢复机会；预下单释放租约用原租约值CAS，不清掉后续请求的租约。代码未提供假微信域名配置或生产模拟成功HTTP入口。
- 默认MOCK，缺商户时页面不出假码，WECHAT模式隐藏模拟付款且后端拒绝旧入口绕过。SDK网络请求在DB事务外；真实模式缺配置拒绝启动。私钥/APIv3密钥从只读挂载文件加载，Git/Docker忽略私有目录和约定私钥文件。
- 新增008/009迁移、可选Compose覆盖层/模板与stack入口，以及[接入说明](../../docs/WECHAT-PAY.md)。
