# T059 普通商城与秒杀履约闭环

2026-11-02，Asia/Shanghai。关联G01/G03/G06/G08。目标：补齐本地演示商城从选款到收货的核心闭环，用户已选择MOCK支付。真实收款/寄送与生产门禁不在本轮完成声明中。

## 实现

- 原价立即购买、服务器购物车、数量修改/移除、收货地址新增/删除、地址/商品快照、多SKU原子合并结算和幂等键冲突检查。
- 普通待支付→支付→发货→收货；待支付取消/超时恢复普通库存，未发货全额退款只恢复一次，已发货拒绝直接退款。普通订单独立模型，仅消费未划拨SKU库存，原秒杀Redis/MQ链路不变。
- 秒杀订单补填收货地址、手工发货、确认收货，原PAID库存事实不变；发货与退款争用订单锁，已发货不能财务直退。
- 管理员审计补货（幂等、数量边界、操作者）与普通/秒杀混合发货视图；普通订单/原MOCK账本各自只读对账。
- 新增005/006/007迁移，不覆盖历史SQL、订单、库存账本或用户卷。商品详情补充unallocatedStock字段，普通购买与活动价格分开呈现。
