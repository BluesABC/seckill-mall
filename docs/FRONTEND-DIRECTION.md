## 2. 设计规范

| 项 | 规范 |
| --- | --- |
| 色彩 | #111主文字/按钮/页脚；#FFF背景；#F5F5F5表面；#626262次文字；#E5E5E5边框；#D62820秒杀/促销强调。成功/失败状态保留语义区分 |
| 字体 | Arial + PingFang SC/Microsoft YaHei/Noto Sans CJK SC；无需外网字体。Hero clamp(42px,4.6vw,72px)、粗体850、行高1.12；区块25–36px；正文12–15px；价格15–27px粗体 |
| 间距 | 4/8/12/16/24/32/48/64的节奏；桌面内容最大1536px，左右4%，手机5–6% |
| 图片/卡片 | 商品1:1灰底，object-fit:contain保全鞋型；下方类别、名称、价格/折扣。参考图无厚外框，本项目默认无阴影，hover轻微放大 |
| 圆角 | 图片直角；尺码/配色4px；搜索/主按钮全圆角；清单抽屉直角。实际参考优先于skill默认卡片12–16px |
| 行动 | 黑底白字普通按钮、#D62820秒杀按钮、白底黑边次按钮；disabled0.4透明；焦点2–3px可见，触控动作至少约44px |
| 响应式 | 覆盖640/768/1024/1280/1440，额外390px手机；首页商品手机2/平板3/桌面4列，目录桌面按Nike参考3列，窄屏2列 |
| 动效 | hover放大、画廊查看细节；尊重prefers-reduced-motion；不强制自动轮播/滚动动画 |

## 3. 信息架构与组件树

```text
App.vue — 认证/验证码/稳定requestId/订单/路由/清单状态
├── 主导航 + 公告 + 搜索 + 清单入口
├── ShopFront.vue
│   ├── 首页：跑者Hero → 运动分类 → 秒杀鞋款 → 品牌宣言 → 日常轮换
│   ├── 目录：分类/关键词/价格筛选 → 排序 → 网格/加载更多
│   └── 秒杀：场次筛选 → 活动时间/鞋款/订单库存占用进度
│       └── ShoeCard.vue — 鞋图/名称/价格/折扣/库存快照
├── ShoeDetail.vue — 图库/局部放大、配色、真实尺码、倒计时、抢购/清单
├── ShoppingBag.vue — 原生dialog抽屉，移除/数量1/清单入口
├── #/cart — 清单/参考合计/逐款抢购入口
├── #/request、#/order、#/orders — 原有真实异步交易闭环
└── Admin.vue — 商品/活动/用户/订单/恢复与SKU展示属性维护
```

尺码来自服务端SKU的sizeEu。未上架尺码置灰，没有伪造尺码库存；当前演示每款一个真实尺码SKU。目录/详情代码可选择同goodsId下已返回的不同SKU，但后台新增多规格的专门入口尚未扩充。SKU一旦分配活动库存，规格元数据锁定，不能事后改写已售尺寸。

清单按用户分区保存在localStorage，访客另用guest分区；切账号不会共享已登录用户清单。清单不预扣，数量固定1（契约限购）；逐款验证码→真实受理/生成订单→单笔MOCK支付，不展示并不存在的合单/优惠券/普通购物车结算接口。

库存进度为`(initialStock-availableStock)/initialStock`，含义为已确认订单占用的数据库快照，不能当作实时Redis预扣或“已售件数”；页面注明在途请求可能尚未计入。价格/时间/最终资格仍由服务端校验。

## 4. 关键页面代码

实现文件为`src/web/src/ShopFront.vue`、`ShoeCard.vue`、`ShoeDetail.vue`、`ShoppingBag.vue`、`App.vue`；Vue3 script setup + TS。Tailwind4.1.14/官方Vite插件用于工具类，主题与参考图细节在sports.css；style.css保留共用订单/管理/表单基础。构建方式遵循[官方Vite集成](https://tailwindcss.com/docs/installation/using-vite)。

## 5. 替换与接入

- 品牌：App.vue、ShopFront.vue、index.html的SNKR//DROP与原创文案。
- 主题：sports.css的`--color-accent`/#D62820、@theme；共用状态样式继续保留。
- 商品图片：public/assets内以版本名保存；实际imageUrl来自MySQL。服务端仅允许安全`/assets/...`路径，不把UI截图/外部品牌商品图作为线上资产。图库第二视图为同一原图的局部放大，不虚构不存在的后跟/鞋底实拍。
- 元数据：先迁移003_sneaker_attributes；ADMIN PATCH /api/admin/skus/{id}维护sizeEu/category/colorway，分配活动前完成；没有客户端价格写回。
- 商品/活动：统一api.ts DTO及既有真实goods/activities接口。原有身份、请求、订单、模拟支付、未知结果恢复契约保留。活动initialStock新增只读快照字段。
- 运行/清理：见[FRONTEND-RUNTIME](FRONTEND-RUNTIME.md)；WSL原生构建、浏览器与SQL证据见V009。生产部署仍在S6。
